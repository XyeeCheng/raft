# Raft 分布式键值存储系统项目

## 项目概述
本项目实现了一个基于 Raft 算法的分布式键值存储系统。Raft 算法是一种用于管理分布式日志的共识算法，它为分布式系统提供了高可用性和一致性。本项目包含多个模块，实现了从基本的 Raft 算法核心逻辑到分布式键值存储的完整功能。

## 项目结构
### 主要包及其功能
1. **`raft`**：实现了 Raft 算法的核心逻辑，包括日志管理、选举、日志复制、日志压缩等。
    - `raft_log.go`：负责日志的存储、操作以及快照处理。
    - `raft_election.go`：处理节点的选举过程，确保集群中有领导者。
    - `raft_replication.go`：处理领导者向追随者复制日志的过程。
    - `raft_compaction.go`：实现日志压缩功能，通过快照减少日志存储空间。
2. **`labrpc`**：提供简单的 RPC（远程过程调用）库，用于节点间通信，支持可靠和不可靠通信模式及并发 RPC 调用。
3. **`labgob`**：处理数据的序列化和反序列化，采用 Go 语言的 GOB 编码。
4. **`porcupine`**：用于验证系统的线性一致性，提供检查操作和事件的工具。
5. **`shardctrler`**：负责分片控制，处理集群的配置管理，如加入、离开组等操作，并进行负载均衡。
    - `state_machine.go`：实现分片控制器的状态机。
6. **`shardkv`**：实现分片键值存储，支持多组服务器间的分片管理和数据迁移。
7. **`kvraft`**：基于 Raft 算法实现简单的键值存储系统，支持 `Get`、`Put` 和 `Append` 操作。

## 运行环境
- **编程语言**：Go
- **依赖库**：项目中已使用 `labrpc`、`labgob` 等自定义库，确保这些库文件完整。

## 编译和运行
### 编译
确保你的 Go 环境已正确配置，在项目根目录下，使用以下命令编译代码：
```bash
go build
```

### 运行测试
项目包含大量测试用例，可通过以下命令运行测试：
```bash
go test -run PartA -race
...
go test -race
```
不同模块的测试用例分布在各自的包中，例如 `raft` 包的测试用例在 `raft` 目录下的测试文件中。
